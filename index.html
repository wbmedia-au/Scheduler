01

02

03

04

If your team already has a Bin ID, paste it here → Save. Everyone uses the same Bin ID with their own API key.

📐 Filename Convention

Asset files in Dropbox must follow this naming pattern for URLs to build automatically:

ClientPrefix_DD.MM.YY.ext

Examples:  PiccoloMe_14.05.26.mp4  ·  Doughkyo_21.05.26.jpg

Reels/Videos → .mp4  ·  All other types → .jpg

The prefix must match exactly what's saved in the client profile.
